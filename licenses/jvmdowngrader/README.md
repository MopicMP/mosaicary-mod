# JvmDowngrader

The jars for the game versions on Java 8 (1.16.5 and older) contain copies of Java 9 to 17 classes and
methods from JvmDowngrader's `java-api` (xyz.wagyourtail.jvmdowngrader, version 2.0.1), put in by
`build.gradle.kts` under `com/mopicmp/mosaicary/jvmdg`. JvmDowngrader is by William Gray and is licensed
under the GNU Lesser General Public License 2.1 (`LGPLv2.1.md`, terms in `LICENSE.md`).

The mod's source, from which those jars are built, is public: https://github.com/MopicMP/mosaicary-mod
Source of JvmDowngrader: https://github.com/unimined/JvmDowngrader
